## Tech Stack 🛠️

Here's what powers my portfolio:

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Language:** TypeScript & JavaScript
- **UI Library:** React 19
- **Styling:** Tailwind CSS 4
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** react-icons
- **Smooth Scroll:** react-scroll
- **Blog Feed:** rss-parser

## Getting Started 🚀

### Prerequisites

- [Node.js](https://nodejs.org/) 18.18+ (Node 20+ recommended)
- npm

### Installation & Development

```bash
# Install dependencies
npm install

# Start the dev server (http://localhost:3000)
npm run dev
```

### Available Scripts

| Command         | Description                                  |
| --------------- | -------------------------------------------- |
| `npm run dev`   | Start the local development server           |
| `npm run build` | Create an optimized production build         |
| `npm run start` | Run the production build                     |
| `npm run lint`  | Lint the codebase with ESLint                |

## Project Structure 📁

```
.
├── app/              # Next.js App Router (pages, layout, routes)
│   ├── blog/         # Blog route
│   ├── layout.tsx    # Root layout
│   └── page.tsx      # Home page
├── components/       # Reusable UI sections (Home, About, Skills, etc.)
├── public/           # Static assets
├── design-system/    # Shared design tokens / primitives
└── next.config.ts    # Next.js config (security headers)
```
